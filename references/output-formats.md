# Output formats

Use these as defaults, not rigid forms. Omit irrelevant sections and combine outputs when the user's request spans multiple capabilities.

## Career direction

Save a dated outcome with:
- profile snapshot;
- 2–4 growth directions;
- evidence for each;
- existing strengths;
- material gaps;
- one immediate action per direction;
- main risks;
- reality check.

## Vacancy fit

Save the vacancy source and a dated analysis containing:
- role snapshot;
- key requirements;
- must-have and nice-to-have evidence mapping;
- overall fit assessment;
- material gaps;
- application strategy;
- CV positioning changes.

Requirement tables may use: Match / Partial / No evidence / Gap.

## CV review

Save a dated review containing:
- positioning assessment;
- highest-impact changes;
- concrete replacement wording;
- evidence gaps;
- optional complete tailored version when requested.

## Interview review

Save a dated review containing:
- what went well;
- what weakened the interview;
- reusable stories and wording;
- new confirmed facts;
- unconfirmed observations;
- preparation priorities.

## Chat response

Lead with the decision or main conclusion. Keep process detail out of the chat unless it helps the user make a choice. Link or name any workspace file created or updated.
